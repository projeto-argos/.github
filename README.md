# ARGOS — Configurações da Organização

Este repositório centraliza a apresentação pública e os padrões compartilhados da organização GitHub do projeto ARGOS.

## Estrutura

```text
.github/
├── profile/
│   └── README.md
├── PULL_REQUEST_TEMPLATE.md
├── CONTRIBUTING.md
└── README.md
```

## Finalidade dos arquivos

- `profile/README.md`: apresentação exibida na página principal da organização.
- `PULL_REQUEST_TEMPLATE.md`: roteiro para revisão das alterações.
- `CONTRIBUTING.md`: orientações para colaboração da equipe.

## Organização do trabalho

- O Jira é utilizado para acompanhar demandas, responsáveis, prioridades e prazos.
- O GitHub é utilizado para armazenar e versionar código e documentos.
- Cada alteração relevante deve ser realizada em uma branch própria.
- Alterações concluídas devem ser integradas à `main` por meio de Pull Request.
- Senhas, credenciais e informações pessoais não devem ser versionadas.
